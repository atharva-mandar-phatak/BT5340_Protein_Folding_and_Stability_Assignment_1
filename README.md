# BT5340: Protein Folding and Stability - Assignment 1

## Overview

This repository contains the materials and code for **Assignment 1** of the course *BT5340: Protein Folding and Stability*. The assignment focuses on analyzing the folding behavior of specific protein segments (short sequences of 4-10 residues) based on the intrinsic phi-psi angle preferences of amino acids and their immediate neighborhood.

## Objective

The primary goal of this assignment is to investigate how the phi-psi angle preferences of amino acids influence the folding patterns of short protein segments. By examining these preferences in the context of their local sequence environment, it is possible to extract meaningful insights into protein folding mechanisms.

## Contents

The repository includes:

- **Code**: Scripts for analyzing phi-psi angle distributions and their impact on folding.
- **Data**: Example datasets to test and validate the analysis.
- **Documentation**: Instructions for running the code and interpreting results.

## Key Concepts

- **Phi-Psi Angles**: Dihedral angles in proteins that define backbone conformation.
- **Local Sequence Context**: The influence of neighboring residues on folding behavior.
- **Protein Folding**: The process by which a protein achieves its functional three-dimensional structure.
